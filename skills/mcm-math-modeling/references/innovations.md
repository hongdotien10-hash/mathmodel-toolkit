## 什么是评委眼中的「创新」

数学建模竞赛的「创新」不等于科研创新。评委认可的创新是：

> **在合理解决本题的前提下，模型比「标准做法」多走了一步，且这一步有逻辑依据、有对比验证、有实际效果。**

三个层次：

| 层次 | 描述 | 评奖对应 |
| --- | --- | --- |
| L1 无创新 | 直接套用标准方法，没有改造 | 省三/省二（H 奖） |
| L2 局部创新 | 在标准方法上做了有针对性的改造或组合 | 省一/国二（M/F 奖） |
| L3 系统创新 | 从问题本质出发构造新框架，或跨领域方法成功迁移 | 国一/国二（F/O 奖） |

**关键原则**：创新必须有「为什么这样做更好」的论证，不能只是「我们用了 XX 方法」。论证方式：理论分析、数值对比、或归谬法（说明不用此改进的后果）。

## 创新的五个维度

每个维度的创新都可以带来加分。不需要每个维度都创新，但至少需要在 1-2 个维度上有亮点。

### 维度 1：模型结构创新
- 不是用现成模型，而是根据问题特征重新设计模型结构
- 例：标准做法用单层优化 → 你设计了双层规划（上层分配资源，下层优化调度）
- 例：标准做法用独立模型处理各子问题 → 你设计了一个统一框架，子问题之间共享中间变量

### 维度 2：求解算法创新
- 不是直接调库，而是针对问题特征改进算法
- 例：标准遗传算法收敛慢 → 你设计了自适应交叉率，根据多样性动态调整
- 例：标准 LP 求解 → 你利用问题的特殊结构（如网络流结构）设计了更快的专用算法

### 维度 3：数据处理创新
- 不是常规标准化/缺失值填充，而是深度挖掘数据隐含结构
- 例：发现数据隐藏在时间维度上的周期模式，将其编码为特征
- 例：从高维数据中通过领域知识（而非纯 PCA）推导出低维物理变量

### 维度 4：评价/检验创新
- 不是只做 ±10% 灵敏度，而是系统性的鲁棒性分析
- 例：用了全局敏感性分析（Sobol 方法）识别关键参数
- 例：构造了对抗场景（worst-case analysis）验证模型极限

### 维度 5：表达/可视化创新
- 用原创概念图把复杂关系直观化
- 例：把三个子问题的模型关系画成一张统一的框架图
- 例：用一张图同时展示参数空间、可行域和最优解位置

## 优化类创新阶梯

### L0：标准做法（省三/省二级别）
- 线性规划 / 整数规划 / 非线性规划，直接调 scipy/pulp/gurobi
- 多目标：加权和法

### L1：局部创新（省一/国二级别）
- **双层/多层规划**：上层决策影响下层可行域，逐层优化
- **鲁棒优化**：在约束中考虑参数不确定性（如 Soyster 鲁棒对等式）
- **Benders 分解 / 列生成**：利用问题结构分解为 master problem + subproblem
- **ε-约束法处理多目标**：保留一个为主目标，其他转为 ε-约束，画 Pareto 前沿
- **自适应权重**：不是固定权重，而是根据求解进度动态调整

### L2：系统创新（国一级别）
- **分布式鲁棒优化 (DRO)**：用 Wasserstein 距离或矩信息构造不确定集
- **随机规划 with 场景树**：用历史数据生成场景，做多阶段随机规划
- **逆优化**：从已有最优解反推目标函数权重，再做预测
- **物理信息神经网络 (PINN)**：把约束嵌入神经网络损失函数，无需求解器
- **算法-模型联合设计**：不是先建模再求解，而是建模时就考虑求解可行性

### 创新触发问题

做优化题时，问自己：
1. 标准模型忽略了什么结构？（层次、时序、不确定性、耦合）
2. 约束有没有特殊结构可以利用？（全单模、网络流、拟阵）
3. 多目标之间有没有自然的层次关系？（先保证可行性，再优化成本）
4. 参数是不是确定的？（如果参数有误差，最优解会不会变？）

## 预测类创新阶梯

### L0：标准做法
- ARIMA / 指数平滑（时序）
- 线性回归 / 随机森林 / XGBoost（回归）
- LSTM（深度学习）

### L1：局部创新（省一/国二级别）
- **分解+预测+重构**：EMD/VMD/小波分解 → 各分量独立预测 → 重构
- **组合预测**：多个模型加权组合，权重由历史误差动态确定
- **特征工程**：从领域知识构造物理特征（如从日期提取星期、节假日、季节虚拟变量）
- **区间预测**：不是点预测，而是 Bootstrap 生成预测区间
- **迁移学习**：用相关领域数据预训练，目标数据微调

### L2：系统创新（国一级别）
- **因果推断 + 预测**：先做因果发现（PC 算法/LiNGAM），再在因果图上做预测
- **物理方程 + 数据驱动混合**：已知物理方程 + 数据学残差（如 ODE + Neural ODE）
- **时空图网络**：捕捉空间依赖（图神经网络）+ 时间依赖（注意力机制）
- **贝叶斯分层模型**：对多层级数据结构（城市→区→街道）建分层先验
- **在线学习/自适应预测**：新数据到来时模型自动更新，不重新训练

### 创新触发问题

做预测题时，问自己：
1. 数据有没有多层次结构？（空间层级、时间周期、类别嵌套）
2. 有没有已知的物理/业务规律可以利用？
3. 预测的不确定性有多重要？（要不要区间预测）
4. 多个预测目标之间有没有关联？（要不要联合预测）

## 评价类创新阶梯

### L0：标准做法
- AHP（主观赋权）
- 熵权法（客观赋权）
- TOPSIS（排序）

### L1：局部创新（省一/国二级别）
- **组合赋权**：AHP + 熵权法，主客观结合，通过离差最大化或其他准则确定组合系数
- **灰色+TOPSIS**：灰色关联度替换 TOPSIS 的欧氏距离，适合数据稀疏场景
- **VIKOR**：考虑群体效用最大化和个体遗憾最小化，更适合决策偏好折中
- **云模型**：将模糊性和随机性统一建模，替代传统隶属度函数
- **多级指标体系**：不把 20 个指标全放一层，而是分层评价，每层独立做 AHP/熵权

### L2：系统创新（国一级别）
- **动态评价 / 时序 TOPSIS**：不是评价一个截面，而是评价一段时间的变化趋势
- **社会网络分析 + 评价**：考虑评价对象之间的网络关系（如城市间的经济联系）
- **DEA + Malmquist 指数**：不仅评价效率，还分析效率的时间演化
- **鲁棒评价**：模拟权重扰动，分析排名稳定性和翻转条件
- **博弈论组合赋权**：把主客观赋权方法视为博弈参与者，用纳什均衡求组合权重

### 创新触发问题

做评价题时，问自己：
1. 评价对象之间有没有关联？（独立性假设合理吗？）
2. 评价是静态的还是动态的？（只看一个时间点，还是看趋势？）
3. 排名的稳定性如何？（权重稍变，排名会翻转吗？）
4. 主客观权重冲突时怎么办？（用什么准则协调？）

## 机理类创新阶梯

### L0：标准做法
- ODE 建模（SIR, Logistic, Lotka-Volterra）
- 蒙特卡洛仿真

### L1：局部创新（省一/国二级别）
- **变系数/时变参数**：不是常数参数，而是参数随状态或时间变化的分段函数
- **多仓室扩展**：如 SIR → SEIR → SEIQR，每增加一个仓室有明确的物理含义
- **随机微分方程 (SDE)**：在 ODE 上叠加随机项，描述环境噪声
- **数据同化**：用观测数据实时修正模型状态（如卡尔曼滤波/粒子滤波同化 ODE）
- **灵敏度引导的参数标定**：先用 Sobol 方法筛选关键参数，再用优化算法标定

### L2：系统创新（国一级别）
- **Agent-Based Modeling (ABM)**：从个体行为规则涌现宏观现象，替代宏观 ODE
- **Networked ODE**：在网络上每个节点跑 ODE，节点间通过边耦合
- **Physics-Informed Neural Networks (PINN)**：NN 替代数值求解器
- **反问题求解**：不是给定参数做预测，而是从观测反推参数，再做情景分析
- **多尺度建模**：微观（个体）→ 介观（群体）→ 宏观（系统），不同尺度用不同方法桥接

### 创新触发问题

做机理题时，问自己：
1. 系统中个体的异质性重要吗？（重要 → ABM；不重要 → ODE）
2. 环境噪声/随机性是否影响结论？（是 → SDE 或蒙特卡洛）
3. 参数是从数据估计的还是拍脑袋的？（拍脑袋 → 需要反问题求解或灵敏度分析证明拍脑袋不影响结论）
4. 有没有空间维度？（有 → PDE 或网络上的 ODE）

## 跨领域方法迁移库

这里的核心思想：**把 A 领域的成熟方法用在 B 领域的问题上，因为底层数学结构相似。**

| 来源领域 | 方法 | 可迁移到的数学建模场景 | 迁移的条件 |
| --- | --- | --- | --- |
| 物理学 | 模拟退火 | 任意组合优化问题 | 能定义能量函数（目标函数+罚函数） |
| 物理学 | Ising 模型 | 二值决策、聚类、图像分割 | 决策变量是二值的，有邻域相互作用 |
| 物理学 | 熵/自由能 | 评价赋权（如熵权法）、模型选择（AIC/BIC 本质是信息） | 需要度量不确定性或复杂度 |
| 生物学 | 遗传算法 | 任意黑箱优化 | 能编码解、定义适应度、设计交叉和变异算子 |
| 生物学 | 神经网络 | 非线性拟合、特征学习、代理模型 | 有足够数据且可解释性要求不太高 |
| 生物学 | 蚁群算法 | 路径规划、TSP、网络路由 | 问题可建模为图上路径搜索 |
| 生物学 | 粒子群优化 | 连续空间优化 | 变量连续，能定义群体行为和速度更新规则 |
| 经济学 | 博弈论 | 多方决策、资源竞争、策略分析 | 有多个独立决策主体，各自有收益函数 |
| 经济学 | 投入产出分析 | 多部门/多子系统耦合、资源流动 | 系统间有输入输出关系，有线性消耗系数 |
| 经济学 | Gini 系数/Lorenz 曲线 | 评价公平性/均衡性 | 需要度量分布不平等程度 |
| 经济学 | 实物期权 | 不确定条件下的投资/决策时机选择 | 决策可推迟，不确定性随时间揭示 |
| 社会学 | 社会网络分析 | 节点重要性排序、社区发现、信息传播 | 对象间有关系网络 |
| 生态学 | Lotka-Volterra | 竞争、共生、捕食关系建模 | 两个以上群体有互动，可用微分方程描述 |
| 生态学 | 生态位模型 | 多目标权衡、资源分配 | 需要描述多维度下的最优区域 |
| 流行病学 | SIR/SEIR | 信息传播、创新扩散、谣言控制 | 有传播机制，群体可分区（易感→感染→恢复） |
| 交通工程 | 排队论 | 服务系统、生产调度、呼叫中心 | 有到达过程、服务过程、队列规则 |
| 交通工程 | 元胞传输模型 | 流体/物料流动、供应链 | 密度-流量关系已知，守恒律成立 |
| 控制论 | PID 控制 | 动态系统调控、库存管理 | 有设定值/实际值/误差，需要反馈调节 |
| 控制论 | MPC 模型预测控制 | 多步决策、滚动优化 | 有预测模型，需要在线滚动优化 |
| 信号处理 | 傅里叶/小波变换 | 周期检测、去噪、特征提取 | 数据含周期分量或需要频域分析 |
| 信号处理 | 卡尔曼滤波 | 噪声数据的状态估计、传感器融合 | 有状态方程和观测方程，噪声假设满足 |
| 运筹学 | DEA 数据包络分析 | 效率评价、标杆分析 | 多输入多输出，不需要预设函数形式 |
| 地理学 | 空间计量/空间自相关 | 区域差异分析、空间溢出效应 | 数据有空间维度，需要 Moran's I 检验 |
| 语言学 | TF-IDF / LDA | 文本数据分析、主题挖掘 | 数据包含非结构化文本 |

## 组合创新模式

**大多数获奖论文的创新不是「发明新方法」，而是「聪明地组合已有方法」。**

### 模式 1：管道组合（最常用）
前一个方法的输出是后一个方法的输入。
```
预测模型 → 优化模型（用预测结果做参数）
评价模型 → 聚类模型（用评分做特征）
机理模型 → 优化模型（用仿真输出做目标函数）
```
创新点：管道中间环节的处理方式（如预测不确定性如何传递到优化）。

### 模式 2：并行组合 + 对比
同一问题用 2-3 种方法独立求解，对比结果。
```
问题 → 方法A ↘
问题 → 方法B → 对比分析 → 综合结论
问题 → 方法C ↗
```
创新点：对比维度不限于精度，还包括计算效率、可解释性、数据需求。

### 模式 3：互补组合
两种方法互相弥补缺陷。
```
方法A（强项：全局搜索） + 方法B（强项：局部细调）
客观赋权（熵权法） + 主观赋权（AHP）→ 组合权重
物理模型（已知规律） + 数据模型（未知残差）→ 混合模型
```
创新点：为什么这两个方法互补？（必须论证，不能只说「互相补充」）。

### 模式 4：层次/嵌套组合
外层方法决定内层方法的选择或参数。
```
外层：聚类 → 每类独立建模
外层：AHP → 确定各子目标权重 → 内层：各子目标独立优化
外层：灵敏度分析 → 识别关键参数 → 内层：关键参数精细建模
```
创新点：层次的划分逻辑（为什么不全部放在一层？）。

### 模式 5：对抗/博弈组合
两种方法扮演对立角色，通过对抗达到更好的结果。
```
生成模型 vs 判别模型（GAN 思想用于数据生成）
乐观情景 vs 悲观情景（鲁棒决策）
主方法 vs 对抗验证（adversarial validation）
```
创新点：对抗的规则设计（为什么这样设计？）。

## 伪创新识别清单

以下不是真正的创新，论文中不要把它们当亮点写：

| 伪创新 | 为什么不算创新 | 怎么改正 |
| --- | --- | --- |
| 「我们用了 XX 方法」（XX 是标准方法）| 使用标准方法不是创新 | 说明为什么选它而不是 YY 方法，做了哪些针对性调整 |
| 「我们改了一个参数」 | 调参不是创新 | 除非参数调整有理论依据，且显著改变了结果 |
| 「我们做了很多张图」 | 数量 ≠ 质量 | 每张图要有论证目的，且图之间有逻辑关系 |
| 「我们用了 Python」 | 工具选择不是创新 | 不提 |
| 「我们参考文献很多」 | 不是创新 | 不提 |
| 「综合考虑了多个因素」 | 因素多 ≠ 模型好 | 说明如何筛选和加权因素，以及为什么这样处理 |
| 「使用了最新的 XX 模型」 | 新旧不是优劣 | 说明为什么这个问题需要 XX 模型的特征，而不是因为它新 |
| 「用深度学习」但没有对比 | 复杂度 ≠ 优势 | 必须和简单模型对比，证明复杂度带来了性能提升 |
| 「做了灵敏度分析」（只做了 ±10%）| 标准要求不是创新 | 除非灵敏度分析方法本身有创新（如全局敏感性分析） |

## 创新自检清单

建模完成后，对照此清单评估创新性：

### 基本门槛（没有则不合格）
- [ ] 每个模型选择都有「为什么不选其他方法」的论证
- [ ] 关键参数不是拍脑袋，有依据（数据估计、文献参考、灵敏度分析）
- [ ] 至少有 1 个地方比「标准做法」多走了一步

### 省一/国二级别（满足 ≥2 项）
- [ ] 有 ≥1 个模型是从问题特征出发专门设计（而非直接套用）的
- [ ] 有 ≥2 种方法在多维度对比表中有分析和选择
- [ ] 灵敏度分析超越了 ±10% 单参数扰动
- [ ] 有一张能体现模型整体框架的原创示意图
