## 一、2025 MCM Problem C — Models for Olympic Medal Tables

### C-1｜Team #2510006，南方科技大学（**Outstanding Winner**）
来源：GitHub `git.bytes.zone/Nahuyiur/2025-MCM-ICM-Problem-C`（作者自述 O 奖）

- **模型栈**：线性回归 + ARIMA(0,0,2) + 随机森林的**混合/集成**；蒙特卡洛（每新设项目 1e6 次）处理新增项目；Poisson 推断把期望值转为奖牌数分布。
- **数据增广**：官方 5 文件 + **GDP + 世界排名**；奖牌数与 log-GDP 相关 **r≈0.83**。
- **事件聚类**：**K-means（K=6）** 把约 70 个项目聚为 Aquatics/Ball/Athletics/Gymnastics/Martial-Arts/Motorsports，分类别建模。
- **不确定性**：90% 置信区间；首枚奖牌国家 95% CI = [2.58, 4.87]（ARIMA + 随机森林）。
- **名帅效应**：对历史教练更替（郎平、Béla Károlyi）做 **Fisher 精确检验**，置信度 P≈0.9993；推荐 中国-排球 / 印度-田径 / 巴西-体操。
- **形式化诊断**：ADF（-4.01, p=0.0014）、Ljung-Box（p>0.05）验证残差白噪声与正态。
- **可复用点**：① 集成而非单模型；② 外部数据增广；③ 对新设项目用 MCMC；④ 稳定性分析（阈值 r 在 [0.3,0.7] 波动时结论是否变）。
- 规模约 25 页 + 工作流图 + 多面板图。

### C-2｜Team #2501869，暨南大学（**Outstanding Winner**）
来源：公开论文摘要（Scribd / 社区转载）

- **模型栈**：**Hurdle–Tobit 融合模型**处理奖牌数的"零膨胀 + 离散 + 右删失"；引入 **RCA（显示性比较优势指数）**；对比随机森林/XGBoost，Hurdle-Tobit 在 MSE 与区间覆盖上更优（Hurdle 对强国更好、Tobit 对弱国更好）。
- **名帅效应**：**贝叶斯变点检测**定位"长期低谷后的突变"，配合**记忆增强的数据预处理**区分真实跃升与自增强伪信号；再用 **2SLS（两阶段最小二乘）**估计因果贡献，克服 OLS 内生性。
- **首枚奖牌**：安哥拉 49.2%、孟加拉 46.7%、柬埔寨 42.5%。
- **可复用点**：① 用计量经济模型（Hurdle/Tobit）处理计数数据；② 2SLS 做因果；③ 变点检测定位干预时点。

### C-3（**F 奖**示例，非 O）— 社区题解
来源：CSDN 博客（F 奖学长 + O 奖作者合写）— 仅作 F 档参考

- LSTM 预测奖牌；BP 神经网络预测首次夺牌；Shapiro-Wilk 正态检验 + Spearman/Pearson 相关；**PELT 变点检测**找名帅效应；**AHP-TOPSIS** 为"应优先聘请名帅的项目"打分排序。

> 对比要点：O 论文普遍有**集成/计量模型 + 外部数据 + 因果推断**；F 档多为**单一 ML 模型 + 变点 + 多准则评价**。

## 二、2024 MCM Problem C — Momentum in Tennis（网球势头）

### 2024-C-1｜Team #2418251
来源：CSDN O 奖论文翻译

- **模型栈**：RNN 计算单局发球/接发获胜概率 → 定义"势能点"（发球得分、破发点、连得、非受迫失误、跑动）→ **PCA** 降维取 3 主成分 → **MSVM 支持向量机**建势头模型 → **ARIMA** 预测累积势头；单局势头与胜率相关 0.704 / 0.729。
- **可复用点**：机器学习链条（RNN→PCA→SVM→ARIMA）+ 相关性验证 + 敏感性分析 + 给教练的 Memo。

### 2024-C-2｜Team #2401298
来源：CSDN O 奖论文翻译

- **模型栈**：**双时间贝叶斯网络**；用 **Ljung-Box Q 检验 + 游程检验**检验随机性（未能拒绝随机性原假设 → 势头效应微妙而非压倒性）；用**信息熵下降**度量各因素对势头的重要性。
- **可复用点**：统计检验驱动的严谨论证；贝叶斯网络 + 隐变量；用"证伪"而非"贴金"的姿态处理争议概念。

### 2024-C-3｜Team #2425454
来源：CSDN 文库 O 奖论文

- **模型栈**：**Leverage 量化势头捕捉模型**——蒙特卡洛逐点计算胜率 → 定义"杠杆"（赢/输一分对胜率的影响）→ 势头 = 杠杆的指数移动平均；用**游程检验 + 列联表独立性检验**证明非随机（90% 置信下 45.11% 非随机）。
- **可复用点**：把抽象概念（势头）**操作化为可计算量**；独立的多重统计检验互相印证。

## 三、跨年份共性（一般归纳，非具体某篇）

近年 O 论文反复出现的"套路"（可直接作为自评清单）：

1. **模型集成 / 多模型对照**：至少 2–3 个模型并比较优劣，而非单一模型。
2. **数据增广**：官方数据之外引入 GDP、人口、排名、外部数据库。
3. **不确定性量化**：预测区间（80/90/95%）、蒙特卡洛、bootstrap。
4. **因果而非相关**：干预/政策类问题用 2SLS、双重差分、变点检测、贝叶斯。
5. **形式化诊断**：平稳性、白噪声、正态性、交叉验证。
6. **一张总览图**：工作流/技术路线图放第 2 页，交代全景。
7. **摘要结论先行 + ≥3 量化结果**。
8. **敏感性/鲁棒性专章 + 图**。
9. **给决策者的 Memo / 建议**（尤其 ICM）。
10. **AI 使用报告**（2024 起为必需项）。

## 四、如何自行扩充本目录

- **官方**：UMAP Journal（COMAP 会员）每年刊出各题 O 论文摘要与**评委评论**——评委评论最有价值。
- **GitHub**：搜索 `MCM 2025 Problem C`、`美赛 O 奖`，获奖队常公开 repo（论文 + 代码 + 图）。
- **社区译文**：CSDN / 知乎"O 奖论文翻译"系列，按题号+年份检索。
- **检索式**：`<年份> MCM Problem <X> Outstanding paper`、`<年份> 美赛 <题> O奖论文`。

> 记录格式建议：`年份-题号-队号｜模型栈｜数据增广｜验证方式｜图表规格｜可复用点｜来源链接`。
