# 数学建模竞赛的图表实践

## 先分清两件事

数模竞赛的图表要求和期刊投稿是两种不同的约束：

| | 数模竞赛 | 期刊投稿 |
|---|---|---|
| 时间 | 3 天，图往往在最后 12 小时集中产出 | 数月，可以逐张打磨 |
| 排版 | Word 或 LaTeX，图插进正文 | 期刊模板，图单独提交 |
| 硬性规范 | **官方没有** IEEE 那样的图内字号/线宽规定 | 有，且严格执行 |
| 评审方式 | 评委快速翻阅，图要"一眼看懂" | 审稿人逐张审视 |
| 主要风险 | 图糊、字体不统一、风格杂乱 | 格式被打回 |

**重要**：全国大学生数学建模竞赛的《论文格式规范》规定的是论文结构、页面设置、正文字体等，**没有**规定图内文字必须多少 pt。所以 `cumcm` 预设里的 8–9pt 是经验推荐值，不是官方标准——它的依据是"插进 Word 后不缩小、打印出来看得清"。

不要对用户说"国赛要求 8pt"，那是错的。应该说"这个字号在 A4 打印下清晰，且插进 Word 后不会被缩放"。

## 数模场景的真实痛点

按出现频率排：

1. **图太多，来不及逐张调** —— 一篇论文 10–20 张图，每张手调样式不现实。需要一次性统一。
2. **插进 Word 后变糊** —— 默认 `savefig` 是 100dpi，Word 里放大就糊。300dpi 是底线。
3. **图宽参差不齐** —— `bbox_inches='tight'` 按内容裁剪，每张图宽度不同，插进同一栏里边缘对不齐。
4. **中文字体不对** —— 图里是黑体，正文是宋体，看起来不统一。
5. **配色花哨** —— matplotlib 默认色环在投影仪和黑白打印下都难分辨。

第 3 条是最容易被忽略的，也是 `cumcm` 预设默认 `savefig.bbox = "standard"` 的原因。

## 推荐工作流（时间紧张时）

三步，十分钟内能把整篇论文的图统一：

```bash
# 1. 确认本机字体（Windows 一般都有，Linux/macOS 常常没有宋体）
python scripts/journal_fig.py doctor --preset cumcm

# 2. 在绘图脚本开头插入预设（apply 会打印可直接粘贴的代码）
python scripts/journal_fig.py apply cumcm

# 3. 全部图生成完，一次性检查
python scripts/journal_fig.py batch ./figs --preset cumcm
python scripts/journal_fig.py consistency ./figs
```

`batch` 回答"哪些图有问题"，`consistency` 回答"整篇的图风格是否统一"。后者在数模里更重要——评委看到的第一印象是整齐度。

**宽度要提前定**：默认 `apply cumcm` 是 75mm（半栏）。跨满 A4 正文（约 15cm）的图应改用 `apply cumcm --width double`（150mm），否则 300dpi 的文件在 Word 里被放大，实际落到页面上只剩约 150dpi——这正是"插进 Word 变糊"的来源。全篇要么都用半栏、要么都用全幅，不要混。

## 图表类型与选择

`template` 命令提供五种高频图的现成代码：

| 模板 | 用途 | 什么时候用 |
|---|---|---|
| `dual-axis` | 双轴折线 | 两个量纲不同的指标要放在一起看（负荷 + SOC、产量 + 价格） |
| `bar-line` | 柱状 + 折线 | 方案对比 + 趋势，或离散类别 + 连续指标 |
| `band` | 带置信区间折线 | 有预测/拟合，需要体现不确定性 |
| `heatmap` | 相关性热力图 | 多变量相关性分析，几乎每篇数模都用得上 |
| `subplots` | 2×2 子图 | 多个指标并列，省版面 |

选择原则：**能用一张图说清就不要用两张**。评委翻得快，图多不等于分高。

## 常见失分点

- 图里没有单位。`功率` 和 `功率 (kW)` 是两回事。
- 图题（caption）写在图片里。图题应该在 Word 正文里，不在图片上。
- 子图没有 (a)(b) 标号，正文无法引用。
- 坐标轴范围从 0 开始却不必要，导致数据挤成一条线。
- 用了三种以上颜色但只有两条曲线。
- 热力图没有 colorbar，颜色代表什么不知道。
- 直接从别的论文截图，分辨率低且是侵权。

## 美赛（MCM/ICM）的差异

美赛用英文，字体用 Times New Roman 而非宋体，其余与国赛接近。用 `cn-journal` 或 `ieee` 预设都可以，但注意：**美赛没有中文**，所以不需要 CJK 字体，`ieee` 预设更合适。
