# 数据可视化选图决策手册（美赛论文版）

> 核心原则：先想清楚"这张图要证明什么"，再决定图型。同样的数据，不同论点 = 不同图。

## 一图一论点

论文插图的致命错误是"把数据堆成图"而没有观点。每张图只回答一个具体问题：

- 模型预测得好不好？→ 预测 vs 实际散点 + 1:1 线
- A 方案是否优于 B？→ 并排箱线/小提琴 + 显著性标注
- 参数变化如何影响结果？→ 敏感性曲线或热力图
- 变量之间相关吗？→ 相关矩阵 / scatter matrix
- 结果随时间怎么演化？→ 时间序列折线 + 置信带
- 多指标如何综合评价？→ 雷达图或分组柱状图

## 选图速查表

| 数据形态 | 推荐首选 | 次选 | **严禁/不推荐** |
|---|---|---|---|
| 1 个连续变量看分布 | 直方图 + KDE / 箱线图 | 小提琴图 | 饼图 |
| 1 个分类变量看占比 | 横向柱状（按值排序） | 堆叠柱状 | 饼图、3D 饼 |
| 1 分类 + 1 连续，n<10/组 | **stripplot / dot plot**（直接列点） | 箱线+stripplot | 纯均值柱（严禁） |
| 1 分类 + 1 连续，n≥10/组 | **箱线/小提琴 + stripplot 叠加** | 小提琴+箱线 | 仅均值柱 |
| 2 连续变量看关系 | 散点 + 回归线 + R² | 2D 密度/hexbin | 折线（除非 x 有序连续） |
| 时间/剂量 vs 连续 | 折线 + 误差带 | 堆叠面积 | 柱状 |
| 多变量相关（>3 列）| 相关热力图 / pairplot | 网络相关图 | 平行坐标 |
| 矩阵型数据 | 热力图（viridis/RdBu_r） | 标注热图 | 3D 表面、rainbow 色图 |
| 构成占比（随时间或分组）| 堆叠柱 / 堆叠面积 | 100% 堆叠柱 | 饼图 |
| 多指标多方案对比 | 雷达图 | 分组柱状 | 蜘蛛图当饼图用 |
| 配对前后对比 | 配对云雨图（paired raincloud） | 前后折线 | 两个独立柱图 |
| 状态转移/流量分配 | 桑基图（简化为左右条形+流带） | 弦图 | 3D 柱状 |
| 地理空间数据 | 等值线图 / choropleth | 气泡地图 | 3D 地形 |
| 二分类性能 | ROC(`roc_curve`) | PR(`pr_curve`)、混淆矩阵 | 仅报准确率 |
| 分布比较 / 正态性 | ECDF(`ecdf_plot`)、QQ(`qq_plot`) | 直方+KDE | 只报均值±方差 |
| 增减量 / 贡献分解 | 瀑布(`waterfall_chart`)、发散柱(`diverging_bar`) | 分组柱 | 堆叠柱（表增减） |
| 两时点前后对比 | 斜率图(`slope_chart`)、哑铃(`dumbbell_plot`) | 配对云雨 | 两组独立柱 |
| 排序/单序列排名 | 棒棒糖(`lollipop_chart`)、点图(`dot_plot`) | 横向柱 | 3D 柱 |
| 多方案×多指标 | 雷达(`radar_chart`)、森林图(`forest_plot`) | 点图 | 平行坐标当主图 |

## 按美赛题型推荐图型（括号内为 `nature_plot.py` 函数）

| 题型 | 常见分析目标 | 推荐图型 |
|---|---|---|
| 连续型优化/预测 | 模型拟合、趋势预测、参数轨迹 | 折线+置信带(`plot_with_band`)、相图(`phase_portrait`)、扇形预测(`fan_chart`)、响应面(`contour_surface`) |
| 评价/决策 | 方案排序、指标权重、多方案对比 | 雷达图(`radar_chart`)、点图(`dot_plot`)、分组柱(`grouped_bar`)、森林图(`forest_plot`)、特征重要性(`feature_importance`) |
| 分类/识别 | 准确率、混淆、ROC | 混淆矩阵(`confusion_matrix`)、ROC(`roc_curve`)、PR(`pr_curve`) |
| 网络/图论 | 节点关系、流量分配 | 网络图(`network_graph`)、桑基风格流(`sankey_style_flow`) |
| 资源调度 | 甘特/时间线、资源占用 | 时间线(`timeline`)、堆叠面积(`stacked_area`) |
| 微分方程/动力学 | 轨迹、稳定点、相位分析 | 相图(`phase_portrait`)、向量场(`quiver_field`)、收敛曲线(`learning_curve`) |
| 统计推断/验证 | 分布、正态性、残差 | ECDF(`ecdf_plot`)、QQ(`qq_plot`)、残差(`residual_plot`)、预测vs实际(`pred_vs_actual`) |
| 多变量关系 | 相关、聚类、概览 | 相关热图(`correlation_heatmap`)、散点矩阵(`pairplot`)、聚类热图(`clustermap`)、平行坐标(`parallel_coordinates`) |
| 贡献分解 | 增减来源 | 瀑布图(`waterfall_chart`)、发散柱(`diverging_bar`)、龙卷风(`tornado_plot`) |

> 完整 49 图型的代码片段与 caption 模板见 `figure-cookbook.md`。

## 视觉编码优先级

同一组数据，传达效率排序：

1. **位置**（散点、折线）> 
2. **长度**（柱状）> 
3. **角度/斜率**（折线斜率）> 
4. **面积**（气泡、饼图）> 
5. **颜色饱和度**（热图）> 
6. **体积/3D**

结论：**能用位置/长度表示的，绝不使用面积/角度/3D。**

## 常见坑与替代

| 坑 | 问题 | 替代 |
|---|---|---|
| 双 Y 轴 | 强行制造相关性 | 拆成上下子图；或标准化共轴 |
| Y 轴不从 0 开始 | 小差异被夸大 | 从 0 起；或加断裂标记 |
| 彩虹色图（jet/rainbow）| 感知不均、造假峰谷 | viridis/magma/RdBu_r |
| 把分类点连成折线 | 暗示不存在的连续关系 | 散点/柱状 |
| 图例遮住数据 | 信息丢失 | 放图内空白处或图外 |
| 3D 柱状/饼图 | 视角扭曲数值 | 2D 柱状/堆叠柱 |
| 均值柱无原始点 | n 小被质疑 | 箱线+stripplot |
| 色图无 colorbar | 读者无法读值 | 必加 colorbar + 标签 |

## 何时拆图

出现以下情况时，拆成多个子图：

- 同一图中展示 > 5 条线或 > 6 个组
- 两个 y 变量量级差 > 10 倍
- 同时想表达"趋势"和"分布"两种信息
- 不同 panel 用不同单位/量纲

拆图后，用统一的面板标签 (a)(b)(c) 和一致的配色、坐标轴尺度，让读者能横向比较。

## 配色与类别对应

- 同一变量（如"Model A"）在所有图中用同一颜色
- 颜色数量 ≤ 5；超过时用 facet/分面 + 重复颜色
- 连续数据用单色渐变；分类数据用离散色板
- 正负/高低对比用发散色图（RdBu_r）；顺序数据用 viridis
